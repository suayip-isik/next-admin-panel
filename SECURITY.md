# Security Policy

## Supported Versions

Security fixes are applied to the latest `main` branch and the latest release tag.

## Reporting a Vulnerability

Do not open public issues for sensitive vulnerabilities.

Send a private report with impact, reproduction steps, and affected routes or modules to the maintainers through GitHub Security Advisories or the maintainer contact channel.

## Response Targets

- Initial acknowledgement: within 3 business days
- Triage decision: within 5 business days
- Remediation plan or workaround: as soon as impact is confirmed

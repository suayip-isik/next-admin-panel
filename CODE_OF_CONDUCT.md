# Code of Conduct

## Our Pledge

Contributors and maintainers pledge to make participation in this project a harassment-free experience for everyone.

## Our Standards

Examples of behavior that contributes to a positive environment:

- Acting with empathy and respect
- Accepting constructive feedback
- Focusing on what is best for the project
- Showing courtesy toward other community members

Examples of unacceptable behavior:

- Harassment, trolling, or personal attacks
- Publishing private information without permission
- Any conduct that would be inappropriate in a professional setting

## Enforcement

Project maintainers are responsible for clarifying and enforcing this code of conduct.

## Reporting

Report violations through the security contact listed in `SECURITY.md`.
